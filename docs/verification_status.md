# Готовность первого выпуска

Состояние на 12 ноября 2026 года: разработка `0.1.0-dev`, стабильный выпуск **не готов**. Этот документ описывает фактически выполненные проверки, а не только наличие кода.

| Область | Подтверждено | Осталось |
| --- | --- | --- |
| Go, Bash, JavaScript | Linux amd64 build, `go vet`, форматирование и синтаксис; опубликованный commit `21f8d2c` прошёл CI | Проверки следующих изменений |
| Docker-архитектура | Web/Control/Adapter, установка и несколько обновлений на стенде, readiness всей цепочки | Полная приёмка rollback/uninstall и reboot |
| Сохранность Amnezia | При установках/обновлениях панели не изменились ID/PID AWG и DNS, контрольные суммы штатных файлов | Подтвердить также в оставшихся сетевых сценариях |
| UI/API | Предыдущая сборка: 43 браузерные проверки, проверки авторизации, Host/Origin/CSRF, скриншоты | Повторить на текущей Go/Docker-сборке; JetBrains HTTP Client ещё не запускался |
| Прямой выход | Восстановление маршрутов, HTTPS и UDP DNS из namespace на текущем Go runtime | Реальное внешнее подключение AWG |
| Установка WARP | Официальный пакет и регистрация установлены при диагностическом запуске | Объяснить и устранить отказ APT при запуске через основную службу, повторить штатную установку |
| WARP и административный доступ | При включении WARP выявлена потеря SSH | Восстановить доступ, установить причину, исправить и проверить независимое аварийное отключение |
| Политика выхода | Реализованы strict/fallback/возврат и ограниченное восстановление | Принять все сетевые сценарии с галочкой и без неё, DNS/IPv6, отказами WARP и reboot |
| Автоматизация | Три workflow; `actionlint` и [CI для `21f8d2c`](https://github.com/khorevaa/awg-vps-control/actions/runs/43211865762) прошли, включая сборку образов, install/restart/uninstall и upload артефакта | Публикация GHCR, выпуск и проверка опубликованного архива |

Потеря SSH при включении WARP — блокирующий дефект. Повторное включение допустимо только после восстановления административного доступа и подготовки независимого аварийного отключения. Пока причина не устранена и сетевые сценарии не приняты, использовать сборку как стабильный WARP-менеджер нельзя.

Проверка HTTPS/DNS из сетевого namespace не заменяет внешнего AWG-клиента. Проверки первой архитектуры UI не засчитываются повторно для текущей сборки. Новые Go-тесты не создавались; `go test` в текущих модулях сообщает об отсутствии тестовых файлов.

Подробные результаты, реквизиты стенда и исходные снимки хранятся только локально. В публичный документ не включаются адреса, имена серверов, ключи, токены, клиентские профили или сырые журналы.
