# Готовность первого выпуска

Состояние на 12 ноября 2026 года: разработка `0.1.0-dev.2`, стабильный выпуск **не готов**. Этот документ описывает фактически выполненные проверки, а не только наличие кода.

| Область | Подтверждено | Осталось |
| --- | --- | --- |
| Go, Bash, JavaScript | Linux amd64 build, `go vet`, форматирование и синтаксис; опубликованный commit `21f8d2c` прошёл CI | Проверки следующих изменений |
| Docker-архитектура | Web/Control/Adapter, установка и обновления на стенде, readiness всей цепочки. При работающем WARP проверены restart, uninstall/start и rollback в обе стороны: клиентские HTTPS/DNS, native AWG/DNS ID/PID, политика и доступы сохранены | Reboot с работающим WARP |
| Сохранность Amnezia | При установках/обновлениях панели не изменились ID/PID AWG и DNS, контрольные суммы штатных файлов | Подтвердить также в оставшихся сетевых сценариях |
| UI/API | Текущая Go/Docker-сборка: 43 браузерные проверки прошли, включая авторизацию, все страницы, темы, mobile layout и logout; обновлены приватные скриншоты. Отключённый штатный Docker-журнал отображается с объяснением вместо HTTP 502 | Повторить негативные Host/Origin/CSRF-сценарии; JetBrains HTTP Client ещё не запускался |
| Прямой выход | На новой ОС: HTTPS и UDP DNS из namespace с адресом клиентской подсети, прямой выход и WARP подтверждены отдельно | Подключить реальный внешний AWG-клиент |
| Установка WARP | Официальный пакет 2026.8.2115.0 и регистрация установлены штатной командой через основную службу; dpkg подтвердил installed, туннель Disconnected. Причина APT EPERM найдена: systemd удалял CAP_SETUID; исправлено явным AmbientCapabilities без отключения sandbox APT/NoNewPrivileges. Native AWG, доступ и политика сохранены | Повторный setup после холодного запуска прошёл; сетевая приёмка продолжается |
| WARP и административный доступ | После прежней потери SSH добавлены независимый откат и штатное SSH-исключение. На новой сборке подтверждены Connected, Network healthy, клиентские HTTPS с warp=on и UDP DNS. Новое TCP SSH успешно открылось, после него safety confirm принят. Ложный конфликт rule ownership из-за отметки [detached] исправлен и проверен | Завершить весь набор отказов и внешнюю клиентскую приёмку |
| Независимая защита WARP | На dev.2 проверены arm/resume, отказ повторного arm и прежнего SSH, подтверждение новым TCP SSH, остановка timer, пропуск stale expiry. Реальный timer сработал при SIGSTOP основного runtime и занятой внешним процессом host.lock: direct клиента заблокирован, runtime вернулся в held, AWG/DNS ID/PID и native файлы, доступ и политика сохранены. Проверено возвращение direct через canonical guard без установки WARP. После reboot неподтверждённого окна сохранились hold, запрет запуска WARP, конфигурация и политика; панель и SSH доступны. С установленным WARP проверено одновременное SIGSTOP обеих служб: зависший warp-cli истёк по deadline, остальные шаги остановили WARP и сохранили block. Инъекция pending запрещает confirm даже через новый SSH. Исправлен выявленный отказ создания drop-in при umask 077 | Сетевая приёмка подключённого WARP |
| Политика выхода | Принудительная недоступность warp-svc: без галочки клиентский HTTPS блокируется; с галочкой HTTPS подтверждает warp=off; снятие галочки блокирует новый выход. Отдельным keep-alive TLS-сеансом без переподключения подтверждены ESTABLISHED и удаление соответствующего conntrack при снятии галочки и автоматическом возврате в WARP. После устранения отказа supervisor сам запустил WARP и вернул HTTPS/DNS в warp; native AWG/DNS ID/PID, конфигурация и доступ сохранены | Проверить IPv6, восстановление повреждённых правил, работающий WARP после reboot и внешний клиент |
| Автоматизация | Три workflow; `actionlint` и [CI для `21f8d2c`](https://github.com/khorevaa/awg-vps-control/actions/runs/43211865762) прошли. [Публикация Web/Control `v0.1.0-dev`](https://github.com/khorevaa/awg-vps-control/actions/runs/43213111236) успешна; анонимное чтение обоих manifests проверено | Стабильный выпуск после сетевой приёмки |
| Чистая ОС | Bundle из CI установлен заново, затем обновлён до `0.1.0-dev.1`; три контейнера healthy. Установка/обновления панели сохранили IPv4 rules/routes и stateless nft ruleset. AWG установлен отдельно и подключён к панели | Повторные сетевые проверки |

Наличие восьми штатных firewall/NAT rules проверено отдельно и добавлено в readiness. Повторный вызов отклонён; ID/PID, native файлы и журнал установки сохранены. Attach и обновление панели сохранили также rules/routes/nft | Реальное внешнее подключение и совместное управление через Amnezia |

После прежней потери SSH независимое аварийное отключение проверено, новое подключение WARP сохраняет SSH. Полная клиентская и сетевая приёмка ещё не завершена. Пока сетевые сценарии не приняты, использовать сборку как стабильный WARP-менеджер нельзя.

Проверка HTTPS/DNS из сетевого namespace не заменяет внешнего AWG-клиента. Проверки первой архитектуры UI не засчитываются повторно для текущей сборки. Новые Go-тесты не создавались; `go test` в текущих модулях сообщает об отсутствии тестовых файлов.

Подробные результаты, реквизиты стенда и исходные снимки хранятся только локально. В публичный документ не включаются адреса, имена серверов, ключи, токены, клиентские профили или сырые журналы.
