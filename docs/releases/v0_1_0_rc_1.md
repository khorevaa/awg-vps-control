Первый предварительный выпуск AWG VPS Control для личных VPS: диагностика AmneziaWG и управление необязательным Cloudflare WARP.

**Это release candidate.** Стабильный `v0.1.0` ожидает завершения клиентской DNS-пробы, проверки IPv6 и попыток обхода через административное исключение. Эти сценарии не отмечены как пройденные.

## Что входит

- Закрытая веб-панель через SSH-туннель: обзор VPS, клиенты AWG, конфигурация со скрытыми секретами, политика WARP, диагностика и журналы.
- Web, Control и Adapter в Docker; официальный WARP и его восстановление работают на хосте.
- Прямой резервный выход только при установленной галочке; автоматическое возвращение в исправный WARP и прекращение прежних direct-соединений.
- Независимый аварийный таймер WARP, подтверждение через новое SSH-соединение и защита при загрузке сервера.
- Bash-менеджер с четырьмя сервисными пунктами, автоопределением SSH-адреса, обновлением и откатом панели.
- Отдельная явная установка нового AWG в Docker из закреплённых официальных скриптов Amnezia. Установка панели сама AWG не устанавливает.

## Проверки и ограничения

Пройдены 45 браузерных и 18 HTTP-проверок, серверные сценарии отказа WARP, разрешённого fallback, автовосстановления, сохранности AWG и перезагрузки VPS. Настоящий клиент Amnezia подтвердил handshake и HTTPS с `warp=on`. Серверные DNS-пробы также прошли; они не заменяют оставшуюся отдельную DNS-пробу внешнего клиента.

Первый профиль: Ubuntu 24.04, Linux amd64, systemd, уже установленные rootful Docker и Compose, root SSH. Клиенты AWG доступны только для чтения; создание, переименование и отзыв выполняются через Amnezia. Обновление существующего AWG и desktop-клиент запланированы следующими этапами.

## Установка и обновление

Для первой установки скачайте `awg_vps_control_linux_amd64.tar.gz` и одноимённый `.sha256` из assets этого выпуска, проверьте checksum и следуйте [быстрому старту](https://github.com/khorevaa/awg-vps-control/blob/v0.1.0-rc.1/readme.md#быстрый-старт).

На уже установленной панели:

```bash
sudo awg-vps-control update-ui v0.1.0-rc.1
sudo awg-vps-control healthcheck
```

Указывайте точный тег: `latest` не выбирает предварительные выпуски. Перед отдельной настройкой или включением WARP создайте safety-окно по [инструкции](https://github.com/khorevaa/awg-vps-control/blob/v0.1.0-rc.1/readme.md#warp-и-политика-выхода).

Образы: `ghcr.io/khorevaa/awg-vps-web:v0.1.0-rc.1` и `ghcr.io/khorevaa/awg-vps-control:v0.1.0-rc.1`. Установка из bundle собирает локальные образы из тех же готовых бинарников; компилятор на VPS не нужен.

[Полный протокол готовности и оставшиеся проверки](https://github.com/khorevaa/awg-vps-control/blob/v0.1.0-rc.1/docs/verification_status.md).
