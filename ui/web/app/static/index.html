Обслуживание WARP

WARP необязателен. Его установка запускается отдельно и не включает разрешение прямого выхода.

Для первой установки сначала сохраните режим без WARP: оставьте «Использовать WARP» выключенным. Затем установите WARP и включите его в политике.

Восстановление работает с ресурсами панели и WARP. AWG автоматически не перезапускается.
